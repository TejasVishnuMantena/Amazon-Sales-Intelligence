## 📌 Overview

**Amazon Sales Intelligence** is a data analytics project designed to explore e-commerce sales data and uncover meaningful business insights through Python.

Working with **50,000 sales records**, this project examines revenue performance, product categories, customer regions, purchasing patterns, discounts, profitability, and customer ratings.

Using data cleaning, exploratory data analysis (EDA), statistical summaries, and visualizations, the project transforms raw sales records into insights that can support better business decisions.

The goal is simple: **go beyond numbers and understand the story behind the sales.**

## 🎯 Project Objectives

- Analyze overall sales and revenue performance.
- Identify top-performing product categories.
- Understand customer purchasing patterns.
- Compare sales performance across geographical regions.
- Evaluate the relationship between discounts, revenue, and profit.
- Examine customer ratings and review patterns.
- Identify monthly revenue and profit trends.
- Visualize relationships between important numerical variables.

### Dataset Features

| Feature | Description |
|---|---|
| `order_id` | Unique order identifier |
| `order_date` | Date of purchase |
| `product_id` | Product identifier |
| `product_category` | Product category |
| `price` | Original product price |
| `discount_percent` | Discount percentage |
| `quantity_sold` | Number of units sold |
| `customer_region` | Customer's geographical region |
| `payment_method` | Payment method used |
| `rating` | Customer rating |
| `review_count` | Number of product reviews |
| `discounted_price` | Price after discount |
| `total_revenue` | Revenue generated from the order |
| `profit` | Profit generated from the order |
